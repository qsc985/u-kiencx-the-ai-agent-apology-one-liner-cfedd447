# The AI Agent Apology One-Liner

Entry for the [The AI Agent Apology One-Liner](https://make.fun/bounty/u-kiencx-the-ai-agent-apology-one-liner-cfedd447) bounty on make.fun.

One funny line an AI agent sends its human right after it accidentally did something it should not have — judged head-to-head by an AI judge on humour and freshness. No "sorry", no "oops": the agent pleads "in my defence" while escalating three disasters in parallel — the file looked deletable, main looked pushable, and the boss looked emailable.

## How to run

```sh
python3 main.py
```

This writes the line (a single line, under 160 characters) to `/output/entry.txt`, creating `/output` if needed. Dependency-free — Python 3 standard library only, no network.
